# Blood Oath Legacy

Live test storefront. Buildless HTML, CSS and JavaScript, deployed on Vercel.

## Source isolation
This folder lives on the dedicated blood-oath-legacy branch. The wall-chart main branch is not changed. Move this folder to its own repository when repository creation access is available.

## Preview locally
Run `node dev-server.cjs` then open http://localhost:4173.

## Deploy
Vercel project: blood-oath-legacy. Output directory: public. No build or dependency installation required. Deploy this folder as the project root.

## Included
Responsive collection, category filters, product detail dialogs, test size selector, browser-persisted bag with quantity controls, brand story and FAQs. Illustrations are placeholder design concepts; there are no real product claims or prices. Checkout is intentionally disabled. No credentials or personal data collected. Search indexing is disabled during preview.
